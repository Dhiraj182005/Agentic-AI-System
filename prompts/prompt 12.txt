## 5. Backend Analytics API

Inspect the existing API structure and implement endpoints consistent with current conventions.

Suggested endpoints:

### Dashboard summary

`GET /api/v1/analytics/summary`

Return real counts for:
- Total debates
- Completed debates
- Running debates
- Failed debates
- Total messages
- Extracted claims
- Verified claims
- Debates with judgments

### Debate activity

`GET /api/v1/analytics/debate-activity`

Return grouped debate counts over the selected time range.

### Claim verification statistics

`GET /api/v1/analytics/claim-verification`

Return counts by stored verdict and confidence level.

### Agent performance

`GET /api/v1/analytics/agent-performance`

Return aggregate statistics derived from actual stored judgment records.

### Fallacy and argument quality

`GET /api/v1/analytics/argument-quality`

Return available fallacy and argument evaluation aggregates from persisted Module 10 results.

### Recent debates

`GET /api/v1/analytics/recent-debates`

Return a paginated list of recent debates with lightweight summary fields.

You may consolidate or adjust these routes to match the existing project architecture. Do not create redundant endpoints if equivalent functionality already exists.

All endpoints must:
- Require authentication.
- Restrict results to the authenticated user's own debates.
- Respect the existing ownership model and foreign-key relationships.
- Validate query parameters.
- Return predictable response schemas.
- Handle empty datasets correctly.
- Avoid N+1 query patterns.
- Use efficient SQL aggregation where appropriate.
- Avoid exposing another user's private data.
- Avoid retrieving complete transcripts when only aggregate counts are required.

Do not add a new database table unless there is a demonstrated need. Prefer computing analytics from existing persisted records for this module.

If caching is genuinely useful, use the existing Redis configuration with a clear expiration and invalidation strategy. Do not introduce caching complexity without a concrete benefit.
